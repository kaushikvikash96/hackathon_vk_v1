The brain model (Qwen3.6-35B-A3B-FP8 via `agent-brain`) is **not** fine-tuned. It
plans and emits tool calls; the runtime executes them; this adapter writes the
answer from the verified results.

## What the adapter is trained to do

1. Read the structured `EVIDENCE` JSON that `query_data` and `retrieve` produce.
2. State **every** component the question asks for, in 1–3 sentences.
3. Copy numbers, dates, percentages, and signs exactly as pre-rendered in the
   evidence `text` fields — never re-derive or reformat them.
4. Say plainly when the supplied data cannot support the question, naming the
   dataset and the missing period.
5. Classify article sentiment and likely market direction when asked.
6. Emit no reasoning trace. The system prompt carries `detailed thinking off`,
   and training targets contain no `<think>` blocks.

## Hyperparameters

Two profiles, selected with `bash training/run_train.sh [--quick]`. Rank, alpha,
learning rate, sequence length, precision and seed are identical in both, so the
runs stay directly comparable.

| | Quick (`lora_quick.yaml`) | Full (`lora_r32.yaml`) |
|---|---:|---:|
| Max steps | 25 | 100 |
| Warmup steps | 10 | 50 |
| Checkpoint every | 5 | 20 |
| Training examples | 600 stratified | 1,688 |
| Wall time | 30–45 min | 2–3 hours |

Reference-baseline values from `Setup_Instructions.md`: LoRA rank 32, lr 5e-5,
sequence length 512, 100 steps, checkpoint every 20, NeMo container 25.09.
Deviations and reasons are recorded in each config file.

Warmup is scaled with the run rather than inherited — a 25-step run using the
baseline's 50-step warmup would finish before the learning rate reached its peak.

Checkpoints are evaluated and the best is selected on validation loss and
component recall, not on step count. [Record which profile produced the
submitted adapter and which checkpoint was selected.]

## Known limitations

- Sentiment labels inherit whatever bias the Qwen labeller has; only a sample
  was hand-checked.
- Trained at sequence length 512, so very long evidence bundles are truncated
  from the tail. Article text is capped at 6,000 characters before the prompt is
  built.
- The adapter is trained to restate evidence, not to reason about data it cannot
  see. Questions needing a metric the tool layer does not implement will produce
  an honest limitation statement rather than an estimate — by design.
- Sentiment coverage is thin relative to the computed slices, so article-grounded
  questions are the weakest category.
